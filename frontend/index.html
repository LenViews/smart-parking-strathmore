How the System Works

The IoT Smart Parking System is designed as an integrated real-time monitoring solution that combines hardware sensing, embedded processing, and web-based visualization to efficiently manage parking spaces within Strathmore University. The system utilizes infrared sensors installed in each parking slot to continuously detect the presence or absence of a vehicle. Once a vehicle is detected or leaves a slot, the sensor sends a signal to an Arduino UNO microcontroller, which processes the input data and determines the current occupancy status of each parking space. This processed information is then transmitted to a backend server built using a PHP-based MVC architecture running on XAMPP, where it is stored, updated, and managed in a MySQL database. In this architecture, the parking lot functions as a digital twin of the physical parking infrastructure, meaning that every physical parking space is mirrored by a corresponding digital representation in the system. This allows for accurate visualization of space utilization, improved traffic flow management, and reduced time spent searching for parking. By digitizing and automating the monitoring process, the system significantly minimizes human intervention, reduces congestion within the university premises, enhances security by tracking vehicle presence, and optimizes the overall efficiency of parking resource allocation.
